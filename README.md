# ⭕ Tic Tac Toe Game ❌

A responsive, interactive two-player Tic Tac Toe game built using pure HTML, CSS, and Vanilla JavaScript.

View live :- https://tic-tac-toe-eight-pi-60.vercel.app/

---

## 🎮 Features

- **Two-Player Gameplay:** Alternates turns between Player **O** (Red) and Player **X** (Blue).
- **Win & Draw Detection:** Evaluates 8 possible winning patterns across rows, columns, and diagonals, plus draw detection after 9 moves.
- **Dynamic UI Controls:** 
  - The **Reset** button remains hidden until the first move is played.
  - Controls switch to a **New Game** prompt upon game completion.
- **Board Locking:** Automatically disables remaining tiles once a winner or draw is declared.

---

## 🛠️ Built With

- **HTML5:** Semantic structure and game grid layout.
- **CSS3:** Flexbox styling, button states, and theme design.
- **JavaScript (ES6):** DOM manipulation, event listeners, and game logic algorithms.
